Secrets

Write-only values. Each secret a Tool module or the Agent provider declares appears here automatically. The page shows only whether a value is set, its last four characters (hidden for short values), the update time and the active source. A stored value wins over the .env bootstrap; no page ever shows a value.

Replacing writes a new stored value and takes effect on the next request. Clearing removes the stored value: a .env value with the same name applies again immediately, and without one the secret becomes unset. The database is unencrypted, so treat a backup like the secrets it contains.
