Personas

A Persona bundles a voice, a personality prompt and the Agent Filler and Unavailable wording. Selecting one applies the bundle in a single settings transaction, so a stale or missing voice leaves everything unchanged. The personality prompt reaches the Agent path only inside the one labelled system part.
